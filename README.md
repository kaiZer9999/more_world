# More World

Мод для [Cataclysm: Bright Nights](https://github.com/cataclysmbnteam/Cataclysm-BN).  
Mod for [Cataclysm: Bright Nights](https://github.com/cataclysmbnteam/Cataclysm-BN).

Пневматический метатель ножей, книга, экзоскелет и импланты.  
Pneumatic knife launcher, book, exoskeleton, and implants.

## Установка / Installation

1. Скачай архив или склонируй репозиторий.  
   Download the archive or clone the repository.
2. Положи папку `more_world` в `mods` игры.  
   Place the `more_world` folder into the game's `mods` folder.
3. Включи мод при создании мира.  
   Enable the mod when creating a world.

## Содержимое / Contents

- Пневматический метатель ножей / Pneumatic knife launcher
- Книга «Пневматический Мир» / Book "Pneumatic World"
- Малый пневматический экзоскелет / Small pneumatic exoskeleton
- Импланты / Implants

## Требования / Requirements

- Cataclysm: Bright Nights
- Lua API version 2
